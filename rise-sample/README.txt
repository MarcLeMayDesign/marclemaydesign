/rise-sample/

Unzip the Rise export INTO this folder, so that rise-sample/index.html exists.

Export path: Rise → Export → LMS dropdown → "No LMS — Web Only" → .zip

Do not rename or move anything inside the unzipped folder afterwards. A Rise
export contains absolute internal paths and does not survive being relocated.

After the project expires this is the only copy you control, so also keep the
.zip and the course .pdf somewhere outside the repo.

Delete this file once the export is in place.
